## Componentes de Controle e Entrada de Dados (User Interaction)

Desenvolvi uma interface baseada em formulários para aplicar e gerenciar o estado (`@State`) de controles de entrada de dados no SwiftUI:

* **`Button`**: Executa blocos de código específicos e atualizações ao ser tocado.
* **`Link`**: Redireciona o usuário para URLs do navegador.
* **`Toggle`**: Alterna estados booleanos (`true`/`false`).
* **`Stepper`**: Controle numérico para seleções discretas e limitadas.
* **`Slider`**: Barra deslizante.
* **`Picker`**: Menu de seleção que mapeia arrays de dados para o usuário escolher.
* **`DatePicker`**: Escolha da data.
