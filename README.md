## Componentes de Controle e Entrada de Dados (User Interaction)

Desenvolvi uma interface baseada em formulários para aplicar e gerenciar o estado (`@State`) de controles de entrada de dados no SwiftUI:

* **`Button`**: Elemento que executa blocos de código específicos e atualizações de estado ao ser tocado.
* **`Link`**: Componente nativo de navegação externa que redireciona o usuário para URLs do navegador.
* **`Toggle`**: Interruptor binário utilizado para alternar estados booleanos (`true`/`false`) de maneira visual.
* **`Stepper`**: Controle numérico incremental ideal para seleções discretas e limitadas (como quantidade de produtos).
* **`Slider`**: Barra deslizante.
* **`Picker`**: Menu de seleção que mapeia arrays de dados estruturados para que o usuário escolha uma opção.
* **`DatePicker`**: Interface nativa de calendário e relógio para manipulação e captura segura do objeto `Date`.
